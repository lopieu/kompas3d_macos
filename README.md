# Russian
##### **Предупреждение:** 
Данный гайд заработал у меня на MacBook Air M4 16/512 с MacOS 27.2 и с учебной версией КОМПАС-3D v24. Не гарантирую запуск в других конфигурациях.
##### **Начало установки**
Для запуска я использовал [Sikarugir](https://github.com/Sikarugir-App/Sikarugir). Устанавливаем программу, заходим в `Sikarugir Creator`, где устанавливаем `Template` и в `Engine` выбираем `WineCX24.0.7_7`. Нажимаем `Create`, заходим в `Configure.app`. Далее я рекомендую перенести установочный архив КОМПАС-3D в директорию `/Users/имя_пользователя/Applications/Sikarugir/бутылка.app/Contents/drive_c/`, чтобы не было проблем с правами на доступ к пользовательским папкам. 
###### **Настройка Sikarugir** 
В `Configure.app` внутри бутылки нажимаем `Winetricks`, в поиске ищем `ucrtbase2019`, выбираем, также ищем `dotnet48` и `vcrun2022`, выбираем их и нажимаем `Run`. После того, как в консоли будет `Winetricks Commands Finished`, нажимаем `Close`. Далее заходим в раздел `Tools`, где нажимаем `Control Panel (control)`. Внутри нажимаем `Add/Remove Programs`. В новом окне нажимаем `Install`, ищем установочную папку, в ней переходим в `Modules` и выбираем `KOMPAS-3D*.msi`, нажимаем `Open`, и в установочном окне выполняем установку. Далее выходим из всех окон, кроме `Configure.app`. Возвращаемся во вкладку `Configuration`, где в `Windows app` вводим путь `C:\Program Files\ASCON\KOMPAS-3D*\Bin\kStudy.exe или KOMPAS.exe или kHome.exe`, либо сами по кнопке `Browse` находим наш файл программы. Далее жмем `Test Run`. На данном этапе программа уже должна запуститься.
##### **Настройка КОМПАС-3D**
Внутри программы есть проблема в виде прозрачной левой панели с инструментами или деревом объектов. Я же просто перетащил эту невидимую панель параметров в правую сторону, и нажал в ней кнопку дополнительного дерева. После этого все отлично отображалось.
# English
##### **Warning:** 
This guide worked for me on a MacBook Air M4 16/512 running macOS 27.2 with the Educational version of KOMPAS-3D v24. I cannot guarantee it will launch on other configurations.
##### **Starting the Installation**
I used [Sikarugir](https://github.com/Sikarugir-App/Sikarugir) to run it. Install the app, open `Sikarugir Creator`, install the `Template`, and select `WineCX24.0.7_7` under `Engine`. Click `Create`, then open `Configure.app`. Next, I recommend moving the KOMPAS-3D installation archive to the `/Users/username/Applications/Sikarugir/bottle.app/Contents/drive_c/` directory to avoid permission issues when accessing user folders. 
###### **Configuring Sikarugir** 
Inside `Configure.app` for your bottle, click `Winetricks`, search for `ucrtbase2019` and select it. Then search for `dotnet48` and `vcrun2022`, select them as well, and click `Run`. Once the console displays `Winetricks Commands Finished`, click `Close`. Next, go to the `Tools` section and click `Control Panel (control)`. In the control panel, click `Add/Remove Programs`. In the new window, click `Install`, locate your installation folder, go to `Modules`, select `KOMPAS-3D*.msi`, click `Open`, and proceed with the installation in the installer window. After that, close all windows except `Configure.app`. Go back to the `Configuration` tab, and in the `Windows app` field, enter the path: `C:\Program Files\ASCON\KOMPAS-3D*\Bin\kStudy.exe or KOMPAS.exe or kHome.exe`, or use the `Browse` button to find the program file manually. Finally, click `Test Run`. At this point, the program should successfully launch.
##### **Configuring KOMPAS-3D**
Inside the program, there is a known issue where the left toolbar or the object tree appears transparent. I fixed this by simply dragging the invisible properties panel to the right side and clicking the additional tree button inside it. After doing this, everything displayed perfectly.
